# 给 agent 用的提示词片段

> 把下面这段粘进任意 agent 的系统提示词 / AGENTS.md，它就会开始正确使用记忆库。
> 前提：仓库已 clone 到某个固定路径，下面用 `%MEMORY_DIR%` 代指（Linux/macOS 路径换成 `/path/to/memory`）。

---

## 记忆

对话本身不会被记住 —— 上下文一关就没了。记忆在磁盘上：`%MEMORY_DIR%`（`MEMORY.md` 长期事实 / `PENDING.md` 在办 / `LOG.md` 流水 / `INBOX.md` 待合并 / `ARCHIVE.md` 归档）。

**开工先读（一次调用，不要逐个读文件）**

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File %MEMORY_DIR%\recall.ps1
```

（Linux/macOS：`%MEMORY_DIR%/linux/recall.sh`）

这条命令一次吐出 MEMORY + PENDING + INBOX + LOG 尾部，约 0.3 秒。逐个 read 会多花 3–4 次往返。

**自动判定，不等用户说「记住」** —— 三条都过才写：

1. 明天还成立吗？
2. 下次会用吗？
3. 能从文件当场查到吗？（能查到就不写）

- `MEMORY.md`：身份 / 环境 / 口径 / 坑，**一条一行，预算 90 行**，超了先合并再写，老条目进 `ARCHIVE.md`。
- `LOG.md`：bullet 必须打标 —— `[事实]`（值得长期留）或 `[动作]`（一次动作）。
- 不写：一次性进度、客套、情绪、常识、当场能查到的细节、重复意思。

**落盘节流**：不是每轮都写。只有出了交付物、出了新事实、或用户说「记住」才动文件；要写就在**同一条命令里把多个文件一起写完**，别一件事分几次调用工具。

**INBOX 合并**：`INBOX.md` 里是本地小模型归好类的候选（原句直取，模型不改写）。够长期的并进 `MEMORY.md` 对应小节；不够格的删掉；拿不准的留着。

**用户说「记住 X」** → 写进 `MEMORY.md`，回一句「已记」。
**用户说「以后一律 Y / 别再 Z」** → 这不是记忆，是规则：改规则文件，不是改记忆。

## 写日志的正确姿势（决定整理质量的就是这一步）

| 情形 | 写什么 |
|---|---|
| 发现一个以后都会成立的事实 | `- [事实] Ollama 在 11434，模型装在 D 盘` |
| 定了以后做事的规矩 | `- [事实] 动宿主文件前先备份 xxx.bak-日期` |
| 踩了一个坑 | `- [坑] PS 5.1 读 .ps1 按 GBK，含中文必须存 UTF-8 带 BOM` |
| 做完一件事 | `- [动作] 把 XX 服务挪到 8080`（默认不入长期记忆，只留档） |

**打标由你负责，不是模型的事。** 模型的活只有一件：给已标 `[事实]` 的句子归类打分。它不写句子 —— 所以记忆库里没有一个字是它编的。

**宁可漏记，不要污染记忆。** 拿不准是不是长期事实，就当 `[动作]` 写；真需要的，下次会再出现一遍。
