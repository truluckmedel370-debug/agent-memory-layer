# 90 秒演示脚本

> 目标：让一个陌生人在 90 秒内看懂三件事 —— ① 痛点真实 ② 机制聪明 ③ 现在就能跑。
> 形式：录屏 + 字幕，**不配音也成立**（字幕写死，鼠标轨迹清晰）。分辨率 1920×1080，字号调大 130%。

## 分镜

| 时间 | 画面 | 字幕（屏幕上的字） | 操作 |
|---|---|---|---|
| 0:00–0:08 | 黑白空屏，一行大字 | 关掉对话，它就忘光了。 | 无 |
| 0:08–0:20 | 两个终端窗口并排，左边是 agent 会话，右边是 `LOG.md` | 所以我让它把该记的写进文件——每条自已标 `[事实]` 或 `[动作]` | 在 LOG 里敲一条 `- [事实] 这台机器 Ollama 在 11434` |

| 0:48–1:05 | 跑 `recall.ps1`，输出一次吐完 | 开工只读一次：4 个文件 + 体积自报，0.3 秒。90 行封顶，超了先合并。 | `powershell -File recall.ps1`，停在最后那行 `[快照 ... 行]` |

## 旁白（若配音，语速压到 200 字/分）

> 会话一关，AI 就忘光了。
> 所以它把该记的写进文件 —— 每条自己标「事实」还是「动作」。
> 整理时，本地小模型只回答三个问题：归哪类、值几分、是不是已经有了。它不写句子。
> 写进记忆的每个字，都是人写的原话。模型只负责判断留不留。
> 开工只读一次，0.3 秒，还会自报这次花了多少上下文。90 行封顶，超了先合并。
> 每天夜里自动整理，关机错过就补跑。
> 五个 Markdown 文件，六个脚本，零云依赖。

## 录制准备（别在镜头前踩坑）

```powershell
# 1. 字号：Windows 终端调到 18pt 以上，或 PowerShell 里先 > $Host.UI.RawUI.FontSize=20
# 2. 干净的环境：先把数据文件清成模板状态
powershell -NoProfile -ExecutionPolicy Bypass -File init.ps1 -Force
# 3. 预热 Ollama（否则第一次加载模型要等 3 秒，镜头里像卡住）
ollama run qwen3-4b:q4 "hi" | Out-Null
# 4. 录屏：Win+Alt+R（Xbox Game Bar），或 OBS 窗口捕获
```
